# Rukwaro Autospares

A modern digital storefront and parts catalog platform for **Rukwaro Autospares**, built with React 19, TypeScript, Vite, Tailwind CSS, and Supabase.

---

## 🚀 Features

- **Dynamic Catalog & Product Browsing:** Fast filtering, high-resolution imagery, and specifications.
- **Supabase Backend:** Relational schema for automotive inventory, stock management, and customer inquiries.
- **Modern Responsive UI:** Tailored with Tailwind CSS and Lucide React icons.
- **Media & Brand Assets:** Curated brand identity, logos, hero video reels, and research documentation.

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm

### Running the Web App

1. Navigate to the web application directory:
   ```bash
   cd rukwaro-web
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Setup environment variables:
   ```bash
   cp .env.example .env
   # Add your VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY
   ```

4. Start development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
